CSS Positioning

This page demonstrates different CSS positioning techniques

Static - не работают стили top, right, bottom, left и z-index
Relative - работают стили top, right, bottom, left и z-index, у данного блока left: 20%; top: 20px;
Position с (z-index) - чем ниже правило и чем больше z-index у селектора (CSS правила) тем выше (ближе) к пользователю данный обьект, действует на перекрытие других обьектов
This is a container with a relative position.
Absolute - работают стили top, right, bottom, left и z-index
Fixed - Фиксированное позиционирование относительно своего родительского блока
Sticky - работают стили top, right, bottom, left и z-index, у данного блока left: 20%; top: 20px; >
